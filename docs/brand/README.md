# OPD Saathi logo

A teal tile with a white map pin standing on a dotted route: you are here, and this is your way. Colours are the app's own: teal `#0f5f5c`, ink `#1b1a19`, page `#f6f4ef`.

| File | Use |
| --- | --- |
| `opd-saathi-logo-light.png` | Logo with name, on light backgrounds |
| `opd-saathi-logo-dark.png` | Logo with name, on dark backgrounds |
| `opd-saathi-mark.png` | Icon only, teal, 512 x 512. Corner watermark in the video |
| `opd-saathi-mark-white.png` | Icon only, white, for teal or dark footage |
| `opd-saathi-title-card.png` | 1920 x 1080 title card for the start and end of the demo video |

PNGs have transparent backgrounds, except the title card. Each PNG has an SVG source next to it. The SVG text uses Segoe UI and Nirmala UI, so use the PNGs where those fonts are missing.

This is our product logo only. The HackCache '26 and cachedinfo x GCET Jammu logos stay as the organisers supplied them.
